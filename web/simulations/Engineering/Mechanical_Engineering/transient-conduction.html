θ/θ_i = exp(−Bi · Fo) for Bi < 0.1
Bi = h L_c / k (convection/conduction)
Fo = α t / L_c² (dimensionless time)
Biot number decides method: Bi < 0.1 → object is nearly isothermal (lumped capacitance). Bi > 0.1 → internal gradient matters, use Heisler charts or series solution. L_c = V/A for general shapes. α = k/(ρ·cp) is thermal diffusivity.
