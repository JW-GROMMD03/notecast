📖 TEACHING NOTES narrative
B+ tree rules:
1. All leaves at same depth (balanced).
2. Sorted keys within each node.
3. Leaves hold data pointers (or rows).
4. Internal nodes hold only routing keys.
5. When a node overflows → SPLIT.
6. Splits propagate upward; root split grows height.
