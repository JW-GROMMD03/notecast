🔑 The WAL Rule
BEFORE any dirty page is written to disk, all log records up to that page's recLSN must be flushed to the WAL first.

This is the write-ahead invariant. It guarantees that any change visible in the data files is also recorded in the log — so a crash can always be repaired by replaying the log.
