📚 What This Sim Teaches
Every database is a point in a 10-dimensional design space. There is no universal winner. The right design depends on:
• Read/write ratio — MVCC vs LSM
• Contention level — 2PL vs OCC
• Scale requirement — single node vs sharded
• Consistency needs — strong vs eventual
• Latency budget — in-memory vs disk
• Fault tolerance — Raft vs single-copy
