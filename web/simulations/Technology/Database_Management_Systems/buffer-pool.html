🎛️ How Buffer Pools Work
● Frame A fixed-size slot in RAM holding one disk page (e.g. 8KB).
● Pin Count Number of active readers/writers. A pinned frame cannot be evicted.
● Dirty Bit Set when a page is modified. Must be flushed to disk before eviction.
● Ref Bit Set on every access. Cleared by Clock's hand to give second chances.
● Victim Frame chosen for eviction. LRU = oldest unreferenced. Clock = next with ref=0.
