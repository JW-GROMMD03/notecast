📖 COLUMNAR STORAGE immutable · sorted · compressed
Column-oriented: each column stored separately and compressed with RLE/dictionary encoding. Writes create new segments — never modify existing ones. Updates = insert new + mark old as deleted (via delete bitmap). Deletes = mark in bitmap, physically removed by compaction.
