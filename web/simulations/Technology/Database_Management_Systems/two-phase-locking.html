✓ 2PL Guarantees
◆ Serializability — Any schedule where all txns follow 2PL is conflict-serializable.
◆ Growing phase — Every lock acquired BEFORE any release.
◆ Shrinking phase — Once you release ANY lock, you can never acquire another.
✗ Deadlocks possible — 2PL does NOT prevent deadlocks. Only conservative 2PL avoids them (at the cost of needing to predeclare all locks).
