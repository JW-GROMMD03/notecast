🔄 POLLINGactive
CPU spins asking "ready yet?". Wastes CPU cycles. Simple but inefficient.
⚡ INTERRUPTidle
CPU does other work. Device signals via interrupt when done. One interrupt per byte or per word.
🚀 DMAidle
DMA controller transfers data directly to memory. ONE interrupt at the end.
